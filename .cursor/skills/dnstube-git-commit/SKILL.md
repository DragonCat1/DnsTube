# DnsTube 提交说明

- 使用英文或中文短句；前缀建议：`feat:`、`fix:`、`chore:`、`docs:`。
- 说明「做了什么」与涉及模块（如 `dns`、`api`、`web`），避免无关文件混入同一提交。
